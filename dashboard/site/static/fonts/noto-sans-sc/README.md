# Noto Sans SC

完整 Regular（400）与 Bold（700）字重。原项目将其已有的 `../NotoSansSC-Regular.otf` 和 `../NotoSansSC-Bold.otf` 无损封装为 WOFF2，每个字重保留全部 30,890 个 Unicode 映射，以及原有字体元数据与版权声明。源 OTF 路径仅描述当时转换来源，不是本副本运行所需文件。

采用 SIL OFL 1.1 许可，见本目录 `OFL.txt`，来源为[官方项目许可](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)。

正文与标题使用相同中文字体。未提供独立斜体，中文强调由浏览器合成倾斜。字体按需加载，纯英文文章不必下载中文字体。
