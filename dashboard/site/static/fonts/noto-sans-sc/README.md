# Noto Sans SC

Full Regular (400) and Bold (700) faces, losslessly packaged as WOFF2 from
the repository's existing `../NotoSansSC-Regular.otf` and
`../NotoSansSC-Bold.otf`. All 30,890 Unicode mappings per face are retained.
The original font metadata and copyright notices are preserved.

Licensed under SIL OFL 1.1; see OFL.txt, copied from the official project:
https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE

Both Blog prose and headings use these same Chinese faces. No true italic
is supplied: Chinese emphasis uses the browser's synthesized oblique.
Fonts load on demand; English-only articles need not download these files.
