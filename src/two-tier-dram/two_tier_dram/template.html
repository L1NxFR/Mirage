    AISim reports total operator time across layers. The replay distributes that time evenly. It generates top-k entries and routed experts from the overlap settings because AISim does not expose the selected sets. The extension recomputes latency after scheduling. For a single request this gives the same timing as closed-loop scheduling. The model reports a separate upper bound on contention between tier 1 writes and compute reads. Runtime checks enforce tier 1 capacity, data arrival before compute, and link bandwidth.

    Scenario comparisons. Each sweep scenario runs one AISim prediction with 32 decode steps. Results use the steady-state window when available. Otherwise they report the mean and variation across steps after the cache fills.
